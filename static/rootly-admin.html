Rootly Admin

The token, the Pylon-ticket field, and the morning schedule.

Rootly API token not set

From Rootly → Settings → API Keys. Stored encrypted; never shown back.

Pylon ticket field

The Rootly custom field that holds the related Pylon ticket (URL or number). When an incident has no value there, the shared Jira issue is used as the fallback join. Leave unset to rely on Jira alone.

Schedule

Runs as a step of the existing morning pipeline, after the Pylon work: fetch open incidents, evaluate the rules, AI-score what changed. Cost appears in Runs under rootly.

Slack access

AI checks read each incident's Slack channel with the existing QC bot token. That token needs the channels:history scope (and groups:history for private channels), and the bot must be in the channel. An unreadable channel never fails the run — the incident is judged on its Rootly record alone and the AI notes say so.
