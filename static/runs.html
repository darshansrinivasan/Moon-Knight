Automated daily run

Fetches the day's tickets from Pylon, runs the AI checks, and posts the summary to Slack — with no one clicking anything.

Stability — the accuracy measure

There is no human-graded answer key, so accuracy is measured as agreement with the previous run of the same day: the percentage of tickets whose overall grade did not change. Scoring is pinned (temperature 0, fixed seed, enum-constrained output), so on unchanged input this should sit at 100%.

When change is legitimate

Refetching a past day updates tickets: states move, replies arrive, and the response-time check re-measures against the current clock. Grade changes after a refetch reflect changed input, not model drift.

Cost

Token counts come from Vertex per call and are priced from a per-model table — an estimate, shown per run. The models column records which model actually graded, including mid-run fallbacks.
